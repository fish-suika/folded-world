# 折りたたまれた世界（仮）

紙の世界を折りたたんで道を作る、3D 横スクロールアクション。紙でできたキツネ「カミ」を操作して、折り目で世界を折り返しながらゴールを目指す。

- 遊ぶ: `index.html`（同じ内容が `folded-world.html`）をブラウザで開く。公開すると GitHub Pages で遊べる
- 操作: ←→ / A D 移動、Space / W / ↑ ジャンプ、F / J 折る・戻す、U / Shift 戻す（二重折り）、R やり直し、Esc ポーズ、M 音の ON/OFF。スマホは横持ちで画面ボタン
- 全 11 ステージ（ワールド 1〜3 の各 3 ステージ、最終ステージ、小さな欠片 20 個で開くひみつの紙）

## 作り方
- three.js r128（CDN）。外部の画像・音声素材はなく、紙の質感は canvas で生成、音は WebAudio で生成
- `src/` を `sh build.sh` で 1 枚の HTML に結合する（`folded-world.html`、`index.html`、検証用の `verify.html`）
- ステージと調整用の数値は `src/10-config.js`。折りのルール・物理・到達検証は `src/20-logic.js`（three.js なし）
- `verify.html` を開き、タイトルが `OK n/n` なら全検証が通っている（折りのルール・物理・全ステージの到達検証・実物理で動くボットの通しプレイ）
