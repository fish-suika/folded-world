## 決定事項（本人との確認）
- 操作環境は **PC（キーボード）＋スマホ（タッチ）**。ゲームパッドは対象外
- 画面は **横長 16:9**。スマホは横持ち（縦のときは「横にしてください」案内を出してゲームを止める。スキル mobile-landscape-guide の実装を使う）

- 下の「実装計画」を本人が確認してから制作を始める。Phase ごとに本人が遊んで OK を出してから次へ

## 本人の設定資料（原文）

### 1. ゲームの概要
- タイトル： 仮題「折りたたまれた世界」
- ジャンル： 3D横スクロールアクション
- どんなゲーム？： 紙でできた生き物を操作し、紙のような世界そのものを折りたたみながら冒険するゲーム。
- 面白さ・特徴： 世界を折ることで離れた場所をつなげたり、地形を変えたり、隠れた場所を出現させたりできる。世界の変化とジャンプアクションを組み合わせた、独自の体験を目指す。

### 2. ゲームの内容
- プレイヤーがすること： 主人公を操作してステージを進み、世界を折りたたんで道を作りながら、各地に散らばった欠片を集める。
- クリア条件： 各ステージのゴールに到達する。最終的な目標は、集めた欠片と新しい能力を活用して冒険を進めること。
- 成長要素： 欠片を集めることで、新しい折りたたみ能力を獲得する。
- ステージ構成： ステージ制を基本とし、自由な探索や隠し道、寄り道要素を組み合わせる。
- 難易度： 適度な歯ごたえ。工夫すれば突破できる難易度にする。失敗した場合は直近のチェックポイントから再開できる。
- 入れたい要素・演出：
  - 世界を折ると、地形や足場がダイナミックに変化する。
  - 折りたたみによって、それまで行けなかった場所への道が生まれる。
  - 紙ならではの折り目や質感を活かした変形演出。
  - カラフルで幻想的な紙のファンタジー世界。
  - 紙の質感と、美しい光・影・奥行きを活かした3Dグラフィック。

### 3. 制作方針
- まず遊べる状態を最優先で作る。
- 最初は簡単な折りたたみ操作と基本的なアクションを実装し、面白さを確認してから発展させる。
- 細かい仕様・数値・実装方法・ステージ構成は、コンセプトに合うようにClaudeが決める。
- グラフィックや演出は、制作環境に合った方法でできるだけ充実させる。
- 仕様の矛盾や重大な問題があれば、実装前にまとめて報告する。
- まず実装計画を作成し、私の確認後に制作を開始する。
- テストと修正は問題点をまとめて行い、不要なやり取りを減らす。
- 最初から過度に複雑な仕組みを作らず、完成可能な範囲で段階的に拡張する。

## 実装前に報告する仕様上の問題と対応案（Claude）

1. **「世界を折る」が具体的にどういう操作・変化なのか決まっていない**（このゲームの核） → **ステージ＝1枚の紙**として、紙に引かれた **「折り目（点線）」で紙を半分に折り返す** 仕組みにする
   - 折り目は決まった場所にだけある（どこでも折れると難しすぎ・作るのも破綻しやすい）。折り目の近くで「折る」ボタンを押すと、**主人公がいない側の紙** が折り目を軸に 180度パタンと回って、反対側に重なる
   - 重なった側の足場・壁は **折り目を挟んで鏡写し** の位置に来る。→ 遠くの足場が目の前に来る（＝離れた場所をつなげる）、高い崖が低い段差になる（＝地形を変える）
   - もう一度押すと元に戻る（何度でも折り直せる）。まずは同時に折れるのは1か所だけ
2. **「隠れた場所を出現させる」の仕組み** → **紙の裏面** を使う。紙には表と裏があり、折り返された部分は **裏面の絵・足場** が見える。裏面にだけある足場・扉・欠片がある（Phase 2）
3. **折りたたみ中や折った先に主人公がいたらどうなるか** が未定義 → 主人公が乗っている側は動かない（折れるのは反対側）。**折った紙が主人公に重なる場合は折れない**（紙がブルッと震えて音で知らせる）。折るアニメーション中（約0.6秒）は主人公も止める
4. **3Dの見た目と当たり判定のズレ** → 見た目は3Dで紙がめくれる演出、**当たり判定は2Dのマス目**（横スクロールなので奥行きは演出だけ）。折りの結果はマス目の鏡写しで計算するので、見た目と判定が食い違わない
5. **「欠片で能力が増える」と「ステージ制のゴール」の関係** → 欠片を全部集めないと先に進めない作りだと、取り逃したときに詰む。そこで2種類に分ける
   - **大きな欠片**: 各ワールドの最後のステージのゴールにある。取ると **新しい折り能力を必ず獲得**（物語の進行と一緒なので取り逃しがない）
   - **小さな欠片**: 各ステージに3個ずつ、隠し道・裏面・寄り道に置く。集めなくてもクリアできる。集めた数でおまけ（隠しステージ）が開く
6. **新しい折り能力の中身** が未定義 → 段階的に増やす
   - ワールド1: **縦の折り目**（左右に折る）
   - ワールド2: **横の折り目**（上下に折る。崖の高さが変わる）
   - ワールド3: **二重折り**（2か所を同時に折れる。組み合わせのパズル）
7. **「最終的な目標」があいまい** → 全3ワールド×3ステージ＋最終ステージ（計10ステージ、1ステージ3〜5分）。最終ステージのゴールでエンディング。あとから増やせる作りにする
8. **「自由な探索」とステージ制** → オープンワールドにはしない。**ステージ内に寄り道・隠し道がある** 形で探索感を出す（作業量を抑えて完成させるため）
9. **チェックポイント** → ステージ内の旗（2〜3本）。落下・トゲで直前の旗から再開し、**折り状態は旗を取った時点に戻す**（折った状態で詰むことを防ぐ）
10. **主人公** → 「紙でできた生き物」として **折り紙のキツネ「カミ」**（仮）。跳ねるとペラッとしなり、着地でつぶれる。名前・動物は変更可

## 操作（予定）
- PC: ←→ / A・D で移動、Space / W / ↑ でジャンプ、**F / J で折る・戻す**（折り目の近くでだけ）、Esc でポーズ
- スマホ（横持ち）: 左下に ←→ ボタン、右下に「ジャンプ」「折る」ボタン
- 折り目に近づくと点線が光り、「F で折れる」と表示

## 見た目の方針
- 紙の質感: canvas で繊維・ざらつきのテクスチャを生成し、足場・背景すべてに貼る。紙の端は少し白いフチ、折り目には影の筋
- 奥行き: 背景に紙の切り絵を何層も重ねる（山・森・雲）。手前ほど濃く、奥ほど霞む
- 光: 暖かい太陽光＋柔らかい影（three.js の影）。紙が折れるとき、めくれた部分の影が地面を横切る
- ワールドごとに色: ワールド1 若草と空色 / ワールド2 夕焼けの橙と桃 / ワールド3 夜の藍と星の金

## 実装計画

### Phase 1：折りの面白さ確認（1ステージ）
- 主人公の移動・ジャンプ（少し助走・空中制御あり、着地のつぶれ）
- 縦の折り目1種類、折る・戻す、0.6秒の紙がめくれるアニメーション、折れないときの震え
- お試しステージ1つ（折り目3〜4か所、「遠くの足場を引き寄せる」「崖を越える」の2パターン）、ゴール
- 見た目は紙テクスチャの箱と簡単な背景まで。音はなし
- → **ここで本人に触ってもらい、折る操作が面白いか・分かりやすいかを確認**

### Phase 2：ステージの中身
- 紙の裏面（裏にだけある足場・欠片）、トゲ・落下、チェックポイント、小さな欠片
- ワールド1の3ステージ＋ステージ選択、保存（localStorage）
- スマホのタッチ操作と横画面案内

### Phase 3：能力と残りのワールド
- 大きな欠片で能力獲得（横の折り目、二重折り）、ワールド2・3、最終ステージとエンディング
- 小さな欠片の集計と隠しステージ

### Phase 4：演出・音・仕上げ
- 背景の切り絵の層、光と影、折る瞬間の紙の音・パタン演出、紙吹雪、ワールドごとのBGM
- 難易度の調整、操作説明、公開準備
